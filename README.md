# LedgerFlow

A portfolio-grade financial management application.

## Tech Stack

- Frontend: Next.js, React, TypeScript
- Backend: Java, Spring Boot
- Database: PostgreSQL
- Infrastructure: Docker, GitHub Actions

## Project Goals

- Practice production-oriented full-stack development
- Explore software architecture and security
- Build automated tests and CI/CD
- Demonstrate engineering skills through open-source code

## Status

Under active development.
